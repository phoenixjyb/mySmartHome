## 安装净口补充确认

用户2026年10月22日在当前会话明确“是安装净口”，确认此前两处600mm为安装净口宽度。洗碗机两款600–608mm厂家净宽条件满足；蒸烤机三款要求560+8mm，需固定侧衬/安装框收窄，不能继续按600mm柜体模块扣板厚推算。此补充不提供此前未标出的可用净深，也不把洗碗机825mm推算变成实测净高。

## 关键核对修正

- 东芝14.9MB文件是含安装信息的完整手册，不能因公开网页提取失败而当成仅有参数表；已阅读印刷页25安装图。
- 美的508官网手册图只标两侧和顶部间距，网页提取中出现的背部100mm并不在对应图中，未据此作为施工值。
- 松下E531AX需要按手册预留120°开门空间，90°表格不等于所有使用功能均可正常完成。
- SX5和SX5 Pro不得混用手册；SX5/GC5均为约45cm高设备。
- 博世洗碗机导购中矛盾的机身/柜位尺寸未采用；博西冰箱规格书有字段缺项，不据其缺项补写深度。
