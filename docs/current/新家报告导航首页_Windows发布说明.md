# 新家报告导航首页：Windows 发布说明

2026-10-22 新增家庭统一入口，汇集四个主要报告和两个早期家具页面。沿用现有 Windows 独立静态报告服务及 HTTPS 分享入口，新增 `home/index.html`；不替换原来的家具总览 `index.html`，六个旧链接保持可用。

## 页面与维护

- [导航首页源码](../../exports/新家报告导航首页_2026-10-22.html)：单文件 HTML/CSS、内联 SVG，无脚本和第三方资源。
- [本地打包器](../../scripts/package_family_report_home.py)：限定六条相对报告链接及两个页内锚点，拒绝私有路径、分享凭据和资源依赖；输出 `index.html` 与字节数/SHA-256 清单。
- 六条目标依次为厨房电器、洗烘、智能家居、家具 V3、阳台 V2.1、法式中古家具总览。前四项集中显示，后两项标为早期方案。
- 导航使用相对路径，面向 Windows 报告树发布；在仓库 `exports/` 里直接打开不能代替正式站点的跳转验证。

```sh
python3 scripts/package_family_report_home.py /absolute/new/package/home
```

## 发布范围

用户已授权发布到现有 Windows 网站。发布前重新读取并核验当前静态服务、全部147个既有允许文件、六个目标及 PhotoHouse 登录边界。复制当前报告树至新版本，只新增首页并合并允许清单；预检通过后只切换独立静态任务 Action，保存回滚资料。

不改 PhotoHouse 登录、媒体、数据、API、其他任务、HTTPS 网关、证书、防火墙和端口。具体主机、分享链接、任务备份及完整操作回执仅存放在 Git 外私有目录。

## 验证结果

已发布。新首页8,538字节，六个既有页面及其资源保持原字节，共148个允许文件全部通过公网HTTPS状态码、长度、SHA-256和TLS检查，隐私响应头保持。

PhotoHouse API进程身份、UI字节及登录边界未变，匿名会话仍为401；其他81个任务定义和静态任务Action以外的全部字段保持。旧版本及任务回滚资料保留。

正式首页在 Edge 1462px桌面完成视觉检查，六张卡片逐一点击到正确目标并返回；本地同包390px手机宽度无横向溢出，标题、早期方案和页内锚点已检查，临时视口已恢复。家庭手机移动网络尚未实测。
