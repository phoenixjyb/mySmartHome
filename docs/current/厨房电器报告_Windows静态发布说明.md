## 尺寸与价格边界

两处600mm是用户确认的安装净口宽度：洗碗机两款厂家要求600–608mm，宽度满足；约825mm安装高度仍是条件推算，净深也未确认。三款蒸烤机要求560–568mm，因此原600mm净口须按型号加固定侧衬或安装框，居中每侧约16–20mm，并落实承托、通风和供电。

冰箱条件保持850宽×600深×1935高mm。8款均待完整厂家安装资料和准确SKU配置确认；两款京东价格仅为2026年10月22日晚条件展示价，补贴资格和最终实付未核验。网页发布不代表任何机型已通过现场安装验收。
