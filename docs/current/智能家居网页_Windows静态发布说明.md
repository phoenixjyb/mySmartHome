# 智能家居采购与网络架构：Windows 静态网页

本页是采购复核的浏览器视图，沿用现有 Windows 家庭报告服务和 HTTPS 分享入口，在独立子路径显示。它展示采购候选与设计，不是家庭设备的实时管理后台。

## 内容来源与生成

- [采购复核](双十一前智能家居采购复核_2026-10-22.md)：决策依据和待确认项。
- [采购 CSV](../../inventory/procurement_2026-10-22.csv)：29 类项目的型号、首批数量、目标数量、已有记录、条件及验收。
- [网页生成器](../../scripts/generate_smarthouse_report.py)与[模板](../../scripts/templates/smarthouse_report.html)。采购卡片从 CSV 生成，架构/试点/说明文字由模板维护；变更时应同步复核。
- [离线 HTML](../../exports/智能家居采购与网络架构_2026-10-22.html)：无第三方脚本、字体、样式和图片依赖，可离线打开。

```sh
python3 scripts/generate_smarthouse_report.py
python3 scripts/package_smarthouse_report.py /absolute/new/package/smart-home
```

打包器只生成一个 `index.html` 和字节数/SHA-256 清单，不连接 Windows、不发布、不改服务。发布页不得包含本机文件路径、账号、网络地址、施工图联系信息或分享凭据。

## 发布范围

用户已要求用现有 Windows 机器托管，与之前的家具/洗烘报告方式一致。执行前需重新核实正在运行的独立静态任务、解释器、入口、配置、清单和回环监听，不能把历史 PID 当当前状态。

1. 复制当前全部允许公开文件到新版本目录，旧文件逐字节保留，新增 `smart-home-20261022/index.html`，合并白名单。
2. 服务入口、模块、分享前缀、回环端口、HTTPS 网关保持原值；仅更新独立静态任务的版本目录/配置校验值。保存原任务 Action/XML，预检通过后切换，失败恢复原 Action。
3. 不修改 PhotoHouse 的数据库、媒体、权限或登录，不修改/重启其 API 和其他后台任务；不改证书、域名、防火墙和公网端口。
4. 全部既有文件与新增网页分别做 HTTP/HTTPS 字节哈希核对；TLS 正常校验，匿名验证 PhotoHouse 仍要求登录。复核 `no-store`、`no-referrer`、`noindex` 响应头，检查桌面和手机宽度的真实页面与交互。

分享入口采用既有的持链接可访问方式。具体主机、地址、随机分享链接、任务备份和操作回执仅保留在 Git 外的私有操作目录；链接仅交付给用户。网络架构图中 VLAN 是目标规划，现有 XDR3068 的多 VLAN/WireGuard 能力未验证；网页不启用任何设备写控制。

2026-10-22 已发布到现有 Windows 独立静态服务。脱敏回执见 [Windows 发布验证](../../references/智能家居网页_2026-10-22/Windows发布验证_2026-10-22.json)。

- 新增单页 62,680 字节，29 张采购卡片、5 条网络分支；生成器、脚本语法、页内锚点、外部资源和私有信息检查通过。
- 公网 HTTPS 对 138 个白名单文件逐一核验状态码、长度和 SHA-256，全部通过；原有 137 个家具/洗烘文件保持原字节。TLS 正常校验，隐私响应头和禁止索引策略通过检查。
- 独立静态任务运行正常；PhotoHouse API 进程身份未变，其他 81 个任务定义未变。PhotoHouse UI 字节保持一致，匿名会话接口仍返回 401。
- 已在 Edge 检查最终线上桌面排版；本地同版布局在 390 像素视口无横向溢出。线上采购型号搜索和初期/完整架构切换通过。
- 家庭手机移动网络尚未实测；商品库存、成交价格、实物兼容和现场安装仍按采购表逐项确认。

本地预览服务已停止，正式 Windows 服务继续运行。源码生成、本地浏览器、Windows 服务、公网 HTTPS 和家庭手机移动网络实测分别记录，不互相代替。
